Sensor Scenario Studio · S³

From a scene on the globe to a track on the screen.

S³ is Chatterguru's scenario studio for radar and multi-spectral sensing. You place a sensor and moving targets in a real place, run the sensors over them, and inspect every stage: the signal, the detections, the tracks and the picture each sensor would see.

What each label means.

A simulation can be convincing whether or not it ran. These labels say how each example's results were produced.

Recorded Workbench run

The pictures and numbers were saved from a completed S³ Workbench run and are replayed unchanged. The page lists the source revision and file digests so they can be checked. The scenario itself can still be fictional.

Browser preview

The browser draws the scene and computes what it shows while you watch, from data exported by S³. It is a faithful preview of the scene, not a saved processing result.

Inside S³

One chain, every stage visible.

Each stage keeps its inputs and outputs, so a result can be traced back to the scene that produced it.

  1. SceneA real place: terrain, roads, buildings and land cover from public data, with moving vehicles, drones and aircraft.
  2. Targets3D models of each target, with the scattering points that dominate its radar return.
  3. SensorsAirborne or ground radar, including a four-face phased array, and an infrared camera on the same platform.
  4. Signal chainPulse compression, range–Doppler processing, clutter suppression and CFAR detection.
  5. TracksDetections become tracks; truth, observations and estimates stay side by side for checking.

Real places, public data

Scenes are built on public terrain and map data, so line of sight, terrain masking and clutter come from the ground itself.

Radar and infrared together

The radar's range–Doppler view and an infrared camera look at the same scene from the same platform, at the same moment.

Requirements to evidence

Features are tied to written requirements and automated tests, in the spirit of model-based systems engineering.
