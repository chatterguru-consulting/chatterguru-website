## Intentionally Omitted External Services & Heavy Binaries
To satisfy same-origin Content Security Policy (`default-src 'none'`), keep bundle size below `15,000,000` bytes, and respect third-party service policies, the following items used by the full local Cesium Workbench (`export_cesium_studio`) are **excluded** from the public website bundle:
1. **Live OpenStreetMap Tile Servers** (`tile.openstreetmap.org`): Excluded to comply with the OpenStreetMap Foundation Tile Usage Policy (`https://operations.osmfoundation.org/policies/tiles/`), which prohibits unapproved bulk/third-party hotlinking on public sites. Replaced by static baked local ENU vector road/building geometry.
2. **Esri ArcGIS REST Satellite / Topo Imagery** (`services.arcgisonline.com`): Excluded in strict zero-external-network website preview mode.
3. **CesiumJS 1.119 CDN** (`cesium.com/downloads/cesiumjs/releases/1.119/`): Apache-2.0 licensed, omitted from the static web preview so the page loads offline with zero third-party script requests. The local `mission.czml` download can still be loaded into local CesiumJS or AGI/Ansys STK Desktop.
4. **3D `.glb` Vehicle & Aircraft Meshes** (`models/sedan.glb` 16.7 MB, `models/CarConcept.glb` 11.8 MB, `models/GroundVehicle.glb` 6.1 MB, `models/ToyCar.glb` 5.4 MB, Cesium sample assets, and `models/synth_*.glb`): Excluded from the website bundle both because single `.glb` meshes exceed the 15 MB ceiling and to avoid redistributing third-party GLTF samples outside the interactive local Workbench.
